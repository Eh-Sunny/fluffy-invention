# 🤖 AI 群聊 · 自由参与

一个基于纯前端（HTML + CSS + JavaScript）的 AI 多智能体群聊模拟器。支持同时接入多个 AI 模型（兼容 OpenAI API 格式），实现自由群聊、结构化辩论、流式输出、打断、对话历史管理等功能。

![预览截图](screenshot.png) <!-- 您可以替换为自己的截图 -->

## ✨ 核心特性

- **多 AI 角色管理**：自由添加、编辑、启用/禁用 AI 角色，每个角色可绑定独立的 API 配置、头像（Emoji）和系统提示词。
- **灵活的@ 选择**：通过下拉菜单可**多选**任意 AI 角色，被选中的 AI 将共同响应您的消息。
- **两种交互模式**：
  - **普通回复**：发送消息后，所有被@的 AI 同时流式回复。
  - **群聊模式**（👥 群聊）：开启后，AI 以概率（约 40%）决定是否发言，实现“自由参与、旁观、有想法再介入”的真实群聊体验。
  - **辩论模式**（💬 讨论）：强制所有被@ AI 进行多轮辩论（初步看法 → 相互评价 → 两轮自由辩论），适合结构化讨论。
- **流式输出与打断**：AI 回复时采用流式输出，发送按钮自动变为“停止”按钮，点击可随时中断所有正在生成的内容。
- **对话历史管理**：
  - 所有对话自动保存在浏览器本地（localStorage）。
  - 支持**重命名**、**删除**对话。
  - 随时新建对话，切换对话时自动中断当前流并保存进度。
- **API 配置管理**：支持添加多个 API 配置（Base URL、API Key、模型名称、最大输出 Token），每个 AI 角色可独立绑定。
- **文件上传**：支持上传任意格式文件，文本文件内容自动插入输入框，二进制文件仅显示文件名。
- **输入框自动上移**：聚焦输入框时自动滚动，避免被手机键盘遮挡。
- **完全前端运行**：无需服务器，所有数据存储在浏览器中，隐私安全。

## 🚀 快速开始

### 1. 部署方式
本项目为**单 HTML 文件**，您只需：
- 下载 `index.html` 文件，在浏览器中直接打开即可使用。
- 或部署到任意静态托管服务（如 GitHub Pages、Vercel、Netlify 等）。

### 2. 初次使用
1. 点击右上角 **⚙** 按钮，添加至少一个 API 配置（需要填写 API 地址、Key、模型名称）。
2. 点击左上角 **☰** 菜单，管理 AI 角色（添加、编辑、绑定配置、启用）。
3. 在输入框中输入消息，点击发送或按 Enter 即可与 AI 群聊。

### 3. 群聊模式
点击输入栏的 **👥 群聊** 按钮开启/关闭。开启后，每次发送消息，AI 会自主决定是否发言，模拟真实群聊氛围。

### 4. 辩论模式
输入话题后，点击 **💬 讨论** 按钮，所有被@的 AI 将依次完成“发表看法 → 相互评价 → 两轮自由辩论”的完整流程。

## 🛠️ 技术栈

- 原生 HTML + CSS + JavaScript（ES6+）
- Fetch API（流式请求）
- AbortController（中断控制）
- localStorage（数据持久化）
- 无任何第三方依赖
