# AI 群聊

一个纯前端的单文件 AI 群聊应用，支持多 AI 角色接力发言、多轮讨论、知识库检索、外部平台对接、数据导入导出等功能。所有数据保存在浏览器 localStorage 中，无需后端，开箱即用。

兼容 OpenAI 格式的 API（如 DeepSeek、OpenAI、Moonshot、通义千问等），支持流式输出与中断。

---

## ✨ 功能特性

🤖 多 AI 群聊

· 支持配置多个 AI 角色，每个角色可独立绑定 API 配置、模型和系统提示词。
· 群聊模式：随机打乱发言顺序，AI 依次接力发言，后发言的 AI 能看到前面 AI 的完整回复。
· 并行模式：关闭群聊后，多个 AI 同时回复，互不干扰。
· @ 选择角色：可指定一个或多个 AI 参与本次对话，支持“全部”快捷选择。
· 讨论/辩论模式：自动进行四阶段多轮讨论：
  1. 初步看法
  2. 相互评价与补充
  3. 自由辩论第一轮
  4. 自由辩论第二轮（最终总结）

📚 知识库

· 支持文件夹树形管理，可创建、重命名、删除文件夹。
· 支持手动添加文档，或上传文本类文件（.txt、.md、.json、.csv、.log、代码文件等）自动读取内容。
· 非文本文件保留文件名，作为文件条目存储。
· 支持标签、搜索、编辑、长按删除。
· 对话时自动根据关键词匹配知识库内容，并注入到 AI 上下文中。

🌐 外部平台

· 可添加外部知识库平台（名称、API 地址、API Key、模型），统一检索与引用（当前为模拟实现，便于后续扩展）。

💬 对话管理

· 多对话历史记录，支持新建、重命名、删除。
· 自动保存对话内容与标题。
· 一键导出/导入 JSON 备份，可选择导出 API 配置、AI 角色、对话记录、知识库、文件夹、外部平台。

🎨 界面与体验

· 深色 / 浅色主题一键切换。
· 移动端适配，最大宽度 430px，模拟手机界面。
· 流式输出，带光标闪烁动画。
· 支持中断生成（点击停止按钮）。
· 附件上传：文本文件读取内容，图片显示预览，其他文件保留文件名。
· 拖拽文件到输入区即可上传。

⚙️ 配置中心

· API 配置：管理 API 地址、Key、模型列表（支持一键获取模型或手动添加）、最大输出 Token。
· AI 角色配置：头像、名称、绑定 API、选择模型、系统提示词、启用/禁用。
· 知识库：文档与文件夹管理。
· 外部平台：对接主流知识库 API。
· MCP / Skills / 插件：即将上线占位。

## 🚀 快速开始

方式一：直接打开

1. 下载 deepseek_html_20261003_a3d5e1.html（或重命名为 index.html）。
2. 用现代浏览器（Chrome、Edge、Safari、Firefox）打开即可。

方式二：部署到 GitHub Pages

1. 将 HTML 文件重命名为 index.html，上传到 GitHub 仓库。
2. 进入仓库 Settings → Pages，选择分支和根目录，保存。
3. 访问 https://<你的用户名>.github.io/<仓库名>/。

配置步骤

1. 点击右上角 ⚙ 进入配置中心。
2. 进入 API 配置，点击“＋ 新增配置”：
   · 填写配置名称、API 地址（如 https://api.deepseek.com/v1）、API Key。
   · 点击“获取模型”自动拉取，或手动添加模型名称。
   · 设置最大输出 Token（默认 4096）。
3. 进入 AI 角色配置，点击“＋ 新增角色”：
   · 设置头像 Emoji、角色名称。
   · 绑定 API 配置，选择模型。
   · 填写系统提示词（可选）。
   · 勾选“启用此角色”。
4. 返回主界面，输入消息即可开始聊天。

## 📖 使用说明

群聊模式

点击输入框上方的 👥 群聊 按钮开启。开启后：

· 每次发送消息，所有启用的 AI 会随机排序，依次发言。
· 后发言的 AI 会收到前面所有 AI 的完整回复，格式为 [角色名]: 内容。
· 适合让多个 AI 接力讨论、互相补充。

讨论模式

点击 💬 讨论 按钮，至少需要 2 个启用的 AI。系统会自动进行四轮讨论，每轮所有 AI 并行发言，轮次之间依次进行。讨论过程会插入阶段分隔线，便于阅读。

@ 选择角色

点击 @ 全部 按钮，可勾选本次对话参与的 AI。不选任何角色时默认为“全部”。

知识库

· 在配置中心 → 知识库中管理文档。
· 对话时，系统会根据用户输入的关键词匹配知识库标题和内容，将匹配到的条目作为参考注入上下文。
· 支持上传文本文件自动读取内容，非文本文件保留文件名。

附件上传

· 点击 📎 按钮或拖拽文件到输入区。
· 文本文件会读取内容并附加到消息中。
· 图片显示缩略图。
· 其他文件仅保留文件名。

对话管理

· 点击左上角 ☰ 打开侧边栏，查看历史对话。
· 支持新建、重命名、删除对话。
· 点击底部“导出/导入”可备份或恢复数据。

导出与导入

· 导出：选择要导出的数据类型，生成 JSON 文件下载。
· 导入：选择备份文件，勾选要导入的类型，确认后覆盖对应数据。

## 🔧 技术细节

· 纯前端单文件：HTML + CSS + JavaScript 全部内联，无任何外部依赖。
· 数据存储：使用 localStorage，存储键如下：
  · ai_group_configs：API 配置
  · ai_group_current_config_id：当前配置 ID
  · ai_group_agents：AI 角色
  · ai_group_conversations：对话记录
  · ai_group_current_conv_id：当前对话 ID
  · ai_group_knowledge_pro：知识库文档
  · ai_group_folders：知识库文件夹
  · ai_group_platforms：外部平台
  · ai_group_theme：主题设置
· API 协议：兼容 OpenAI POST /chat/completions 接口，支持 stream: true 流式响应。
· 流式解析：手动解析 SSE 数据，逐块更新界面。
· 中断机制：使用 AbortController 中止请求，已生成内容标记为“已中断”。
· 知识库匹配：基于关键词的简单包含匹配，非向量检索。
· 外部平台：当前为模拟实现，仅作为扩展占位。

## ⚠️ 注意事项

1. API Key 安全：所有配置（包括 API Key）都保存在浏览器 localStorage 中，仅适合个人本地使用。请勿在公共设备上保存敏感 Key。
2. CORS 限制：部分 API 可能不允许浏览器直接跨域请求，需要 API 提供方支持 CORS，或使用代理。
3. localStorage 容量：通常为 5–10 MB，大量知识库文档或长对话可能超出限制，建议定期导出备份。
4. 知识库匹配：当前为关键词匹配，并非语义检索，匹配效果有限。
5. 外部平台：目前仅提供配置界面，实际检索为模拟数据。
6. 浏览器兼容：建议使用最新版 Chrome、Edge、Safari、Firefox。部分旧版浏览器可能不支持 AbortController、backdrop-filter 等特性。
7. 模型校验：已修复“已选择模型却提示未选择”的问题，模型从 AI 角色配置中读取。
8. 返回键：配置中心已修复返回键逻辑，支持子页 → 菜单 → 关闭的层级返回。

## 🛠️ 常见问题

Q：提示“未选择模型”怎么办？
A：请进入配置中心 → AI 角色配置，编辑对应角色，确保已绑定 API 配置并选择了模型。如果模型列表为空，请先在 API 配置中“获取模型”或手动添加。

Q：请求失败怎么办？
A：检查 API 地址、API Key 是否正确，模型名称是否有效，以及网络是否可达。部分 API 需要支持 CORS。

Q：群聊模式下第二个 AI 能看到第一个 AI 的回复吗？
A：可以。群聊模式为顺序执行，后发言的 AI 会收到前面所有 AI 的完整回复，格式为 [角色名]: 内容。

Q：数据会丢失吗？
A：数据保存在浏览器 localStorage，清除浏览器数据或更换设备会丢失。建议定期使用“导出”功能备份。

Q：如何更换主题？
A：点击右上角 🌓 按钮切换深色/浅色主题。

Q：支持哪些 API？
A：任何兼容 OpenAI chat/completions 格式的 API 均可，如 DeepSeek、OpenAI、Moonshot、通义千问等。
